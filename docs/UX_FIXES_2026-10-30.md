# 用户体验修复 · 2026-10-30

三个子代理分别检查搜题识别、真题下载、分章练习，通过复现确认并修复以下 9 项问题。

| 页面 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| 搜题 | 更换图片或切到新 PDF 页后，仍保留旧题干、候选及在途搜索 | 更换来源即清空旧匹配，并使旧搜索结果失效 |
| 收藏 | 未加载科目的收藏被误报为试卷已删除 | 进入收藏时按需加载相关科目，加载中显示状态 |
| 工作区导航 | 切换页面后，浏览器后退直接离开应用 | 前进、后退恢复对应的工作区页面 |
| 真题下载 | 首次配置加载期间连续点击，可能启动两批重复下载 | 同时只启动一个下载任务 |
| 真题下载 | 下载时切换科目，ZIP 使用新科目名称，内容仍为旧科目 | ZIP 名称使用下载开始时的科目 |
| 真题下载 | 切科目目录尚未完成或加载失败时，旧选择仍可下载 | 加载新目录前清空旧选择，隐藏旧配套下载入口 |
| 分章练习 | 再次点击当前科目，已选单元被重置为第一单元 | 保留当前单元 |
| 分章练习 | 科目、单元切换不支持浏览历史 | 前进、后退恢复科目、单元及相应下载链接 |
| 分章练习 | 目录失败后一直显示加载中，无法在页面内重试 | 显示失败状态与重新加载按钮，恢复网络后可直接重试 |

源码涉及 `dist/app.mjs`、`dist/papers.mjs`、`dist/chapters.mjs` 和 `dist/chapters.html`。回归测试位于 `tests/app-state.test.mjs`、`tests/papers-state.test.mjs`、`tests/chapters.test.mjs`。
