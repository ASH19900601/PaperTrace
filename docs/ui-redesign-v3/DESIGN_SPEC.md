> 日期：2026-11-01 · 适用：`dist/` 下 `index.html`、`papers.html`、`chapters.html`、`tools.html` 及其 CSS
> 前两版保留在 `docs/ui-redesign/`，仅供对照，**执行时以本目录为准**。
> 为什么要有第三版：见 `RESEARCH.md`。一句话——v1/v2 从宣传海报出发，把一整套流行的“海报 / 粗野主义”默认值搬进了工具界面，因此显得像 AI 生成。

## 1. 定位

PaperTrace 是一个**学生连续使用一两个小时的查题工具**，不是落地页。用户的动作只有三步：

1. 把题目放进来（粘贴、输入卷号、截图）；
2. 在候选结果里认出是哪一道；
3. 打开原卷或 MS。

界面的全部任务是让这三步更快、更确定。品牌感来自**做得可靠**，不来自装饰。

### 1.1 参照物（从这个领域本身取材）

| 参照 | 取用什么 |
| --- | --- |
| 搜索引擎的结果页 | 结果是列表而不是卡片：出处一行、标题一行、摘要两三行、操作一行；蓝色就是“可以点” |
| 学生的纸质复习习惯 | 命中词用荧光笔黄；收藏用琥珀色星标 |
| 试卷与评分标准本身 | 原卷预览是页面里最重要的图像——用真实内容说话，不画示意图 |
| 中文常用工具（作业帮、飞书、语雀等） | 系统中文字体、6–8px 小圆角、浅灰侧栏、浅蓝选中态、虚线上传框——用户已经熟悉，不需要学习 |
| 两张海报 | 只取品牌蓝 `#204FFF` 和 “PaperTrace” 字标。海报继续用于宣传，产品界面不模仿海报 |

### 1.2 原则

| # | 原则 | 判断方法 |
| --- | --- | --- |
| P1 | **每个元素都要说得出它表达什么信息** | 说不出就删：装饰标签、状态点、色条、分割线、图标都一样 |
| P2 | **列表用列表，表格用表格，卡片只给需要比较或选择的东西** | 搜索结果 = 列表；科目 / 试卷 = 表格；学习工具 = 卡片 |
| P3 | **蓝色 = 可以点 / 当前选中** | 链接、主按钮、选中的导航与筛选项。标题、数字、标签不用蓝色 |
| P4 | **文案写功能，不写口号** | 换成别的产品就说不通才对；按钮写动作（“查找试题”“查看 MS”） |
| P5 | **安静的层级** | 层级靠字号 22/17/16/14/13/12 和字重 400/500/600 区分；不用 700 以上、不用大写、不拉字距 |
| P6 | **状态完整** | 加载、空、无结果、错误、禁用、成功都有样式；不只做“有结果”的一张图 |
| P7 | **只改皮，不动骨** | 不改 id、data-*、JS 依赖的类名与 DOM 关系，不改 `.mjs` |

### 1.3 禁止清单（逐条对应 `RESEARCH.md` 的 A1–A15）

- `text-transform: uppercase`、`letter-spacing` 大于 0.02em（A1）
- 等宽字体用于标签、元信息、试卷编号、计时（A2）。等宽只给识别原文、公式片段、`<code>`、工具图标字母
- `border-radius: 0` 的整站直角；2px 及以上的黑色边框；无模糊的偏移投影（A3、A5）
- 标题中单独给一个词上色（A6）
- “大数字 + 小标签”统计块（A7）——统计写成一句话
- 口号式标题、黑色口号条、报头徽章（A8、A9）
- 3px 及以上的彩色左边框（A10）
- 静态 HTML 里给按钮文字加装饰箭头（A11）。新标签页打开的链接保留 `↗`，因为它表示“会离开当前页”
- 导航以外的装饰图标（A12）
- 中文界面里的装饰英文：`SCOPE`、`Text search`、`Image / PDF`、`Private workspace`、`Made for independent learners.`、各页标题上方的英文标语等（A13）
- 不表示状态的状态点（A14）

## 3. 字体

```
--pt-font: -apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei",
           "Noto Sans CJK SC", "Source Han Sans SC", "Segoe UI", Roboto, Arial, sans-serif;
```

中文站点用系统字体是通行做法，也保证离线和国内访问。**不引入 Inter，不做展示字体子集。**

| 用途 | 字号 / 字重 |
| --- | --- |
| 页面标题 `h1` | 22 / 600（手机 20） |
| 区块标题、结果数 | 17 / 600 |
| 结果标题、工具名 | 16 / 600 |
| 搜索输入 | 16 / 400 |
| 正文、按钮、导航 | 14 / 400–500 |
| 元信息 | 13 / 400 |
| 最小字号 | 12（手机底部导航 11 是唯一例外） |

数字统一 `font-variant-numeric: tabular-nums`。

## 4. 布局

- **桌面**：左侧 208px 浅灰侧栏（品牌字标、7 个导航、底部“GitHub 源码”链接），右侧内容区最大宽 1040px，左对齐，左右内距 40px。这是工具类产品最常见的布局，学生不用重新找导航。
- **≤1100px**：侧栏 184px，内距 24px。
- **≤760px**：侧栏变为底部 7 格导航（图标 20px + 11px 文字，选中蓝色）；顶栏显示“PaperTrace 当前页名”；内距 16px。
- 间距：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48。
- 圆角：小标记 4px、按钮与输入框 6px、面板与对话框 8px。
- 阴影：只给浮层（对话框）。卡片、按钮、搜索框都不加阴影；搜索框聚焦用 3px 半透明蓝色焦点环。

## 5. 组件

> 每条规则在 `mockup/reference.css` 都有实现。

### 5.1 按钮

| 变体 | 样式 |
| --- | --- |
| `.btn` | 白底、1px `--pt-border`、6px 圆角、高 36px、14px/500；悬停浅灰底 |
| `.btn.primary` | 蓝底白字；悬停 `--pt-blue-hover` |
| `.btn.small` | 高 30px、13px |
| `.text-btn` / `.preview-btn` | 蓝色文字，悬停下划线 |
| 禁用 | 浅灰底、浅灰字、`not-allowed`，不靠透明度 |

每条结果最多一个主按钮（“查看 MS”）；其余是次要按钮或文字按钮。

### 5.2 表单与筛选

- `select`、文本输入：高 32px、6px 圆角、1px 边框；聚焦蓝框 + 焦点环。
- 筛选项（`.level`、`.dl-chips`、`.dl-quick`、`.tool-filter`、`.chapter-subject`）：未选中白底灰框 / 透明；**选中 `--pt-blue-bg` 底 + 蓝字（+ 蓝色浅框）**。原生单选 / 复选框保留并用 `accent-color` 着蓝，用户一眼就知道是单选还是多选。

### 5.3 搜索框

- 白底、1px 边框、8px 圆角；聚焦时边框变蓝并出现焦点环。
- 顶部两个搜索方式切换：`文字搜题` / `图片 / PDF`，各带一个 16px 图标（图标在这里帮助区分两种输入方式），当前项浅灰底。删掉英文副标题。
- 输入 16px；底部左侧一行提示，右侧“查找试题”主按钮，**不加箭头**。

### 5.4 搜索结果（列表）

```
CAIE · AS & A Level   9702 · 物理   原句 / 编号命中(绿)                       ☆
2024 May / Jun / Paper 22 / Question 5                                     ← 16/600
(a) A [diffraction grating] is illuminated normally with …（荧光笔黄）          ← 14 摘要，最多 3 行
9702_s24_qp_22.pdf · 原卷 p.8 · MS 已检查 · 答案 p.6     展开原卷小问 题目详情 [原卷 ↗] [查看 MS ↗]
────────────────────────────────────────────────────────────────────────────  ← 1px 行分隔
```

- 没有外框和背景，行与行之间 1px `--pt-border-subtle`，上下内距 16px。
- 出处行 13px 灰色；匹配说明用 `--pt-ok` 绿色（它是“这条结果有多可信”的信号）。
- 收藏星：未收藏浅灰，已收藏琥珀色。
- 展开的原卷预览是一个 8px 圆角的带框区域：浅灰标题栏（试卷 · 题号 · 页码 + “查看整页”“打开 PDF”）+ 浅灰底上的原卷图像。
- 列表容器 `grid-template-columns: minmax(0, 1fr)`，防止长内容撑出屏幕。

### 5.5 空状态与无结果

- 空状态：小标题“几种搜法”+ 三条普通列表项（英文原句 / 卷号 / 截图，内容取自现有帮助）+ `#corpusNote`。没有图形。
- 无结果（JS 生成的 `.no-results`）：粗体一句结论 + 建议文字 + 可选的“扩展到全部科目”按钮。

### 5.6 统计

写成一句话，不做大数字：
- 搜题页标题右侧：`13,334 条题目 / 页面可搜索 · 2018–2026 · 已加载 4 / 67 个科目`（数字 600 字重，其余灰色）。
- 题库总览：`72,055 条题目 / 页面索引 · 6,033 份 QP · 5,912 份 MS 已配对或检查 · 67 个科目代码`，用 `·` 分隔（CSS `::before`）。

### 5.7 表格（科目、已索引试卷）

- 外框 1px、8px 圆角；表头浅灰底、12px 灰字、**中文、不大写**；行高约 40px，行间 1px 浅线，悬停浅灰。
- 科目列表：`app.mjs` 输出的 `.subject-card` 结构不变，用 CSS Grid 排成 6 列：`课程 · 代码 | 科目（中 + 英） | 年份 · QP | 题数 | 单位 | 状态`；`.subject-group` 作为分组行；新增静态表头 `.subject-grid-head`。≤1100 去掉状态列；≤760 每科两行。线上 `.subject-card` 是 `<button>`，CSS 同时兼容 `div`。

### 5.8 上传区

`.upload-area`、`.file-label`：1px 虚线框、8px 圆角、浅灰底；悬停 / 拖入时边框变蓝、底色浅蓝。删除 `▧`、`＋` 字符图标，文字与按钮已经说明用途。主按钮“选择文件”。

### 5.9 资料类型标记

`.dl-file-icon`、`.chapter-file-icon`：22px 高的小文字标记，4px 圆角。QP 浅灰底灰字，MS 浅蓝底蓝字，GT / ER / CI 同 QP。

### 5.10 对话框、提示、错误

- `dialog`：白底、1px 边框、8px 圆角、浮层阴影；背景遮罩 40%，不模糊。
- `#toast`：深灰底白字、6px 圆角，桌面在内容区底部居中，手机在底部导航上方。
- `.error-box`：浅红底红字、6px 圆角，不加左边框色条。
- `.reading-part`（小题）可以用 2px 浅灰左线表示缩进层级——它表达的是题目结构。

### 5.11 图标

`icons.svg` 只有 9 个：7 个导航 + 2 个搜索方式（文字 / 相机）。圆角端点、1.75 描边。**按钮、标题、空状态、上传区不加图标。**

## 8. 响应式与无障碍

- 390 / 768 / 1024 / 1440 无横向滚动。
- 手机可点击区域 ≥ 36px，主要操作 ≥ 40px。
