# 多题图片、PDF 搜题与 OCR 改进

## 使用流程

在「图片 / PDF」上传图片或 PDF，点击「识别并分题」。一张图片中的题目分别显示为可选择的卡片，每张卡片显示对应候选试卷。切换卡片同步更新题干、搜索结果和原卷预览。

PDF 支持翻页、当前页框选和「识别整份 PDF」。文字 PDF 优先直接读取文字及坐标；扫描 PDF 逐页识别，本机初步结果先显示，服务器结果随后补充。整份处理显示页数进度，允许停止；已经识别的题目继续可用。跨页续题合并，封面、版权说明、公式表、周期表跳过。文件上限 30 MB。

本机 OCR、可选服务器快速 OCR、可选 LLM 独立并行。先完成的结果立即可搜；快速 OCR 的分题更完整时更新展示。用户主动选题、选择识别来源或修改题干后，较晚完成的引擎不会覆盖其操作。关闭「并行使用快速 OCR」即可仅使用本机 OCR；LLM 有独立开关。服务器识别失败时，本机 OCR 仍可使用。

## 技术选择与来源

- 使用维护中的 [RapidOCR](https://rapidai.github.io/RapidOCRDocs/main/en/install_usage/rapidocr/install/) 3.10.0 + ONNX Runtime CPU，在现有两核 VPS 上运行 PP-OCRv6 Tiny 检测和识别模型。相比原先仅按文字行读取，新增字符置信度和坐标，用于分题及过滤展示杂字。
- 按 [Tesseract 图像质量与页面分割指南](https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html) 将本机识别改为自动页面分割 PSM 3，保留行坐标，预热并复用 worker，透明图片铺白底。
- 使用已有 [PDF.js](https://mozilla.github.io/pdf.js/examples/) 的文字层和坐标，避免对可直接读取的文字再次 OCR。双栏题目按列读取，题内缩进编号保留在同一题中。
- LLM 保持用户指定的 `gpt-6.1-sol` / `low`，提示词返回多道题的边界，独立展示完成状态。

RapidOCR 检测图像长边上限为 1280；横向并排页面提高到 1920，以保留小字。缩放采用 `max`，避免将窄截图的短边放大至整页尺寸。单次服务器推理限制两个计算线程，同一时间处理一张图片。浏览器 OCR 独立进行，服务器排队不会阻塞初次结果。

## 实测

样本为项目原有跳伞题截图、飞机题整页，以及 0620_s24_qp_21 的三题化学页。按 PDF 原文或人工转录统计英文词袋精确率：对识别输出中的英文词逐一计数，与参考词的重合数除以输出词数。数值用于这三张样本的横向比较。

| 样本 | 原 PSM 6 | 新本机 PSM 3 | RapidOCR Tiny |
| --- | ---: | ---: | ---: |
| 跳伞题 | 59.5% | 59.5% | 95.8% |
| 飞机题整页 | 69.9% | 95.4% | 98.5% |
| 化学三题页 | 97.3% | 97.8% | 98.9% |

飞机整页中，参考原文之外的英文词从原先 41 个降至新本机模式 6 个、RapidOCR 2 个。低可信碎片和页边杂字从展示中筛掉，题干内容保留用于搜索。选项按段落显示。

本机预热后的原尺寸截图测试：Tesseract PSM 6 为 0.28 / 0.70 / 0.96 秒；PSM 3 为 0.26 / 0.63 / 1.21 秒。RapidOCR 核心推理约 0.37 / 0.62 / 0.72 秒。VPS 公网测试：跳伞截图预热后 1.84 秒，其中推理 0.50 秒；化学三题页 5.30 秒，其中推理 3.49 秒。实际浏览器化学页本机 OCR 2.1 秒、服务器 OCR 5.3 秒，首次结果由本机先提供。免费 LLM 同次测试 38.6 秒完成，等待期间已可逐题搜索。

真实题库搜索：上述截图共五道题，期望原卷均进入前五；四道为第一候选，化学第三题的同题旧卷排第一，当前卷排第二。两页扫描化学 PDF 在本机验证中拆为六题，选题后对应 Q5 的原卷预览正确切换。将两页并排排入一张图片后，六题均独立识别，保留第六题完整题干。

## 验证与运行

- 全量 Node 测试 81 项通过；后续双栏、逐页并行、版权页脚和显示调整的相关测试 31 项通过。
- 后端 16 项测试通过，包括快速 OCR 的结构化结果、无效图片、来源校验、不可用时静态应用可用，以及现有 LLM/预览接口。
- 真实整份 PDF 测试：化学 40 题，页码 2–14；物理 7 题，跳伞题第 6–7 页合并，原卷中其他题目独立保留。
- 原始测试记录保存在 `.cache/ocr-bench/`，包括 `comparison.json`、`search-report.json`、`vps-api.json`、`node-tests.log`、`final-focused.log`。

安装服务器可选依赖：`python -m pip install -r requirements-ocr.txt`。首次运行下载 Tiny 模型；部署时使用服务账号运行一次识别以检查模型读取权限。静态版本使用已有浏览器 OCR。

VPS 发布目录为 `/opt/papertrace/releases/20261025-multi-question-ocr`，回滚目录为 `20261024-vps-homepage`。发布前使用 `docs/deployment/apply_vps_homepage.py` 保留 VPS 的免费服务说明、可选个人 API 设置、开发者信息及 MIT 页面。此次没有推送 GitHub，也没有更新 GitHub Pages。

公网实际浏览器验证：16 页物理文字 PDF 在 3.6 秒内拆成 7 道题，跨页范围分别显示；两页扫描 PDF 拆成 6 道题，切换 Q5 后原卷预览定位到对应题目。首次扫描 PDF 的服务器等待暴露后，新增本机逐页即时展示，服务器继续完善结果。

末页的版权说明从分题检索文字中剔除，避免压过短题干。PDF 数值与常用单位之间的排版空格在搜索文字中统一，保持展示原文；已针对化学 Q15 的能量数据验证，候选从第六位提升至该科目的第一位。

最终完整试卷检索复核：深国交默认范围内，两份真实 PDF 共 47 道题全部进入前五，其中 44 道排第一。记录见 `.cache/ocr-bench/native-pdf-search.json`。公网浏览器确认物理最后一题回到正确的 `9702_s24_qp_22` Q7。最终扫描 PDF 测试六题全部识别，8.6 秒完成；纯本机模式三题图片 2.5 秒完成；双栏图片本机结果 3.0 秒，RapidOCR 精细结果 10.2 秒，六题正确分开。
